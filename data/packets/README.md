# Referral packets go here (never in git)

Download the 11 de-identified packets from the event's Google Drive folder
(https://drive.google.com/drive/folders/1ISmUtoNCTW3NJNqCQJHJzb6C319RgrXM), choose **Download all**,
unzip, and move `R01.pdf` to `R11.pdf` into this folder.

Rules from the event ground rules:

- Do not commit, copy, post or screenshot the packets. This folder is ignored by git except for this file.
- A black box means "removed for privacy", not "missing". Dates and names are blacked out.
- If a page shows a name, date or number that identifies someone, stop and tell an organizer.
- Keep `eval/decisions.json` out of the extractor's sight. It is for scoring only.
